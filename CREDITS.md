### 🛠️ Core Technologies & Upstream Foundations

Hatcut stands on the shoulders of remarkable open-source engineering:

1. **[The FFmpeg Team](https://ffmpeg.org/)**
   * The powerhouse behind the multimedia universe. FFmpeg's `libavfilter`, `libavcodec`, `libavformat`, and hardware encoder integrations (NVENC, QSV, AMF, VideoToolbox) provide the real-world rendering backbone for Hatcut's graph compiler.

2. **[The Python Software Foundation](https://www.python.org/)**
   * Python's standard library (`http.server`, `subprocess`, `dataclasses`, `hashlib`, `mimetypes`, `threading`, `json`) made Hatcut's "Zero Dependencies" guarantee possible without sacrificing performance or ergonomics.

3. **Open Standards & Specifications**
   * **Subtitles**: SubRip (`.srt`) and WebVTT (`.vtt`) open caption standards.
   * **Color**: Adobe `.cube` 3D LUT (Look-Up Table) specification.
   * **Web Platform**: HTML5 Canvas, Media Source extensions, and CSS Transform compositing.
